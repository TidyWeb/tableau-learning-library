06 · Build the analysis

Story and share: guide a reader through evidence

A story is a sequence of views or dashboards with captions and saved states. It lets the audience follow a line of reasoning rather than receiving every chart at once.

Official story-building help ↗

Follow the LMS in Tableau

Create the Story tab and six saved views

The Story is built after the worksheets and dashboard exist. Each story point is a saved view state: the same sheet can appear again with a different Store, Department or scope.

New StoryUse the bottom tab icon.
Add a pointChoose a sheet or dashboard.
Change scopeUpdate filters at each point.
Save, then sharePublish is a public release.

1. Prepare the filter controls

  1. Return to Sales Dynamics and Forecast.
  2. Show the Store filter and the Action (Dept,IsHoliday,Store) filter as multiple-value dropdowns.
  3. Make the first filter state match the first story point: Store 1 and Department 1.

2. Create the Story tab

  1. Click the New Story icon beside the tabs at the bottom.
  2. Rename the story Retail Analysis Story.
  3. Choose a suitable story size.
  4. Use the sheet/dashboard list on the left to add the first view, then use New story point to create the next point.
  5. Click the caption area below the view and describe the claim made by that point.
Checkpoint: the story point must contain a visible sheet or dashboard. A caption alone is not a new point of evidence.

3. Build the six LMS points

At each point, change the filter or selected bar first, then add or update the story point so Tableau saves that state. Do not assume that changing the current view automatically rewrites an earlier point.

4. Save locally before publishing

  1. Choose File → Save As and save the workbook locally while you are still checking it.
  2. Click through all six story points and verify the captions, filters and totals.
  3. Only then use the Tableau Public publishing command if you explicitly want to make the workbook and its data public.
Public means public: publishing to Tableau Public is not the same as saving the workbook. Anyone may be able to access the published workbook and data.

Story structure

Six points, one narrative

  1. Create a new Story named Retail Analysis Story.
  2. Show the Store and Action (Dept,IsHoliday,Store) filters on the Sales Dynamics and Forecast sheet as multiple-value dropdowns.
  3. Add the Sales Dynamics and Forecast sheet and caption the first point.
  4. Add a blank point and the Store 1 Dept 1 Dashboard; repeat for Store 1 and the whole network.
  5. At each point, deliberately update the filters or selected bar so the point makes a distinct analytical claim.

Narrative discipline

Change the scope, not the facts

Narrow

Store 1, Department 1: what happened to this particular slice?

Middle

Store 1, all departments: does the store-level picture differ?

Broad

Whole network: is the local pattern part of the wider business story?

Good caption: “Store 1 Department 1 shows a declining historical pattern; investigate demand, competition and mix before attributing the cause.”
Avoid: presenting a saved filter state as if it were a new dataset. A story point changes the view’s context; it does not create new evidence.

Official context

What a story can and cannot do

Tableau describes a story as a sequence of visualisations that can communicate context and show how decisions relate to outcomes. Each story point can use a different view or the same view with different filters. Stories are powerful for presentations, but some dynamic dashboard features are limited inside stories, including zone visibility and axis titles/ranges.

Read Creating a Story ↗ and Stories ↗.

Share safely

Saving is not publishing

  1. Save locally while the workbook is still being checked.
  2. Only publish when the data is suitable for public release.
  3. After publication, use the Tableau Public Share control to copy the link.
  4. Remember that Tableau Public workbooks and their data are accessible to anyone.
Release boundary: do not publish confidential, personal or restricted data to Tableau Public. Treat Publish as an external release action, not as the normal Save command.

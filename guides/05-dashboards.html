05 · Build the analysis

Dashboards: make views work together

A dashboard is not a storage box for every chart. It is a designed surface where a reader can see the main result, investigate it, and understand the limits.

Official dashboard best practices ↗

Follow the LMS in Tableau

Build the dashboard from finished worksheets

A dashboard is a new tab that receives worksheets. You do not rebuild the charts inside it. First finish the sheets in Section 4, then place them onto the dashboard canvas.

1. Create the dashboard tab

  1. Click the New Dashboard icon beside the worksheet tabs at the bottom.
  2. Rename the tab Main Dashboard.
  3. Set a fixed or sensible dashboard size before arranging objects.
  4. In the left dashboard pane, find the list of sheets and the Objects section.

2. Place the LMS sheets

  1. Drag a Text object onto the top of the canvas and enter Retail Store Performance and Insights.
  2. Drag Total Numbers near the top.
  3. Drag Sales per Store-Department across the middle.
  4. Drag Sales Dynamics and Forecast and Sales and MarkDowns relationships in Dynamic into the lower area.
  5. Resize the objects by dragging their borders; keep the primary store-department view largest.
Checkpoint: the dashboard should contain four worksheet views plus the title, not a collection of blank containers. If a sheet is missing, return to its worksheet tab and confirm its name.

3. Create the Total Numbers sheet

  1. Return to a worksheet and click New Worksheet.
  2. Rename it Total Numbers.
  3. In the Data pane, choose Create Calculated Field and create Total Sales = SUM([Weekly_Sales_handled]).
  4. Create Total MarkDowns by adding the five prepared Markdown sums shown below.
  5. Drag both calculated fields to Text on the Marks card.
  6. Format them as custom currency in millions and edit the text label to show Total Sales: and Total MarkDowns:.
Total MarkDowns = SUM([MarkDown1_filled]) + SUM([MarkDown2_handled]) + SUM([MarkDown3_handled]) + SUM([MarkDown4_filled]) + SUM([MarkDown5_handled])

4. Make the dashboard interactive and test it

  1. On the dashboard, open the menu on the Store or Year filter card and choose Apply to Worksheets → All Using This Data Source.
  2. Select the main Sales per Store-Department view and click its Use as Filter icon, or choose the equivalent dashboard action.
  3. Test a Store selection, a Department bar selection, and the years 2011, 2012 and All.
  4. Duplicate the dashboard tab, rename it Store 1 Dept 1 Dashboard, then select Store 1 and the Store 1 / Department 1 bar.

Main Dashboard

Assemble the Retail views

  1. Create a dashboard named Main Dashboard.
  2. Add a text title: Retail Store Performance and Insights.
  3. Add Total Numbers near the top.
  4. Add Sales per Store-Department across the main middle area.
  5. Add Sales Dynamics and Forecast and Sales and MarkDowns relationships in Dynamic in the lower area.
  6. Start with a fixed or sensible range size so you know what the audience will see.

Interactivity

Two kinds of filter behaviour

Use as Filter

A selected mark in one view filters other views. In this exercise, selecting a Store–Department bar drives the supporting views.

action

Apply to Worksheets

A filter card is made shared across the relevant sheets. Use “all using this data source” when the same Store or Year selection should control the dashboard.

scope

  1. Make Sales per Store-Department the filter view.
  2. Apply the Store and Year of Date filters to all relevant worksheets.
  3. Test 2011, 2012 and All.
  4. Test a store selection and a bar selection.

Design checks

Make it readable before making it clever

  • Put the main finding or question in the upper-left.
  • Keep the number of views focused; more charts do not automatically create more insight.
  • Use colour consistently and avoid unnecessary legends.
  • Make labels horizontal and readable at the final display size.
  • Test with the user’s likely screen size and interaction path.
Dual-axis warning: two axes can make unrelated scales look visually comparable. Label units clearly and use a single axis where possible.

LMS sensitivity task

Remove the date filter and observe

Remove the November 2011 data-source filter, update the source and compare the Main Dashboard. Record the date range, totals, forecast and trend before and after. A changed forecast is expected: changing the historical window changes the information available to the model.
